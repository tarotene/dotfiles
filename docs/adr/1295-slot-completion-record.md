# ADR-1295 — 作業の枠の時間は予定データに残し、worklog の slot kind は済んだ・やめたの完了記録だけを持つ

- Status: Accepted
- Date: 2026-10-30
- Issue: #1294
- Supersedes: ADR-1291 の D1・D3・D4・D5・D6(`slot` kind の状態・出来事・行の形・読み出し・試験・終端の控え。D2 の kind の名前 `slot` は保つ)

## Context

ADR-1291 は、作業の枠(自分一人でやる、時間枠つきの作業)の状態を、`worklog` の `slot` kind で追うと決めた。時間枠
(`start:`・`end:`)を行に持ち、状態は `scheduled`・`done`・`dropped`、事象は `plan`・`resched`・`done`・`drop`、
読み出しは `slot open`(未了の一覧)と `slot overdue`(終了を過ぎた未了)だった。

その後、前提が変わった。作業の枠の時間の定義は予定データ(Git)に残る。予定データはカレンダーへ射影され、busy と
通知の入力になる。時間の正本が予定データと作業ログの 2 か所にあると、片方だけが変わったときに食い違う。さらに、
作業ログ(vault)はクラウドの実行環境から読めない。時間と未了を作業ログに持たせても、クラウド側で使えない。

作業ログが担う仕事は、白紙で見ると 1 つだけ残る。カレンダー側の情報からは導けない「本人が済んだ・やめたと裁いた」
という事実の記録である。

## Decision

### D1: 時間は予定データに残し、`slot` kind は完了記録だけを持つ

作業の枠の時間の定義は予定データ(Git)の 1 か所に置く。`slot` kind の行は、その枠が済んだ・やめた、の記録だけを
持つ。状態は `done`・`dropped`(どちらも終端)、事象は `done`(none → done)・`drop`(none → dropped)で、どちらも
行為者は person(済んだかどうかは本人にしか分からない。エージェントは本人に確かめて書く)。`scheduled`・`plan`・
`resched` は廃止する。行は `- HH:MM [slot] done: <鍵>` / `drop: <鍵>` だけで、時間枠も Issue も持たない。

軸: 表現不可能 — 時間は予定データの 1 か所、完了記録は作業ログの 1 か所に置き、時間が 2 か所で食い違う状態を
表現できなくする。

### D2: `plan`・`resched`・`slot open`・`slot overdue` を廃止する

時間の正本が射影の入力である Git にあるので、時間を作業ログに複写する `plan`・`resched` は、同じ事実を 2 か所に
書く仕組みになる。時間から導く `open`・`overdue` は、予定データの終了時刻と完了記録の差で決まる値で、読む側
(予定データを持つ側)が `worklog slot closed --json` を読んで導く。作業ログはクラウドから読めないので、
作業ログ側に導く機構を置いても使われない。死んだ機構は消す。

軸: 還元 — 担う仕事が予定データ側にある機構(時間の保持、過ぎた未了の導出)を、作業ログに残さない。

### D3: 鍵は予定データの予定 id にし、同じ鍵に別々の終端は書けない

鍵は予定データの予定 id(kebab-case、数字を含む。例 `light-task-cad-measure-20261026`)で、自分で決める短い id
でなく外から与えられる。書き込み口は、畳み込んだ記録に同じ鍵があれば、同じ事象の再実行を「記録済み」(exit 0)に
し、別の終端は書かずに止める(先に書かれた終端が勝つ)。合流した別の機体の行や手書きで同じ鍵に別々の終端が
書かれたときは、畳み込みが先の終端を残し、`worklog slot check` が食い違いとして出す(exit 1)。`check` は解析
できない行も出す。畳み込みの順は、日付・時刻・出来事・鍵の順で、ノート内の行の位置に依らない。

軸: 表現不可能 — 書き込み口から、同じ鍵に別々の終端を書く経路を無くす。手書きで入った衝突は `check` が検出する。

### D4: 読み出しは `slot closed`、試験は語彙の遷移表の全マスで行う

`worklog slot closed [--json]` は、記録済みの鍵を書かれた順に出す。TSV は `鍵<TAB>状態(done|dropped)<TAB>日付`、
`--json` は `[{"key","state","day"}]`。試験は、語彙 JSON から読んだ表の全マス(none・2 状態 × 出来事 2)で、実装が
表のとおり通す・数えることと、終端から出る出来事が無いこと、同じ鍵の二重終端の拒否、畳み込みが行の読み込み順に
依らず決定的なこと(5 行の全順列 120 通り)を確かめる。語彙の移行は版 3 で、共通の形(ADR-1293)のまま
`scheduled` と 2 つの事象を除き、`carriers` に `cli:worklog` と `skill:daily-desk`(朝の机が本人に確かめて書く)を置く。

軸: 検出のみ — 試験は表と実装のずれを検出するが、ずれを書けなくはしない。

## 先行例との対比

- D1: 作業の枠の時間を予定データの 1 か所に置き、作業ログの `slot` kind は完了記録だけにする。
  先行例: ADR-998(粒度の小さい記録は vault の当日ノート、正本の変更は Git という分担) docs/adr/998-worklog-vault-daily-note.md (取得 2026-10-30)
  差分: 異なる — ADR-1291 は状態の追跡のために時間まで作業ログに複写した。時間の正本が射影の入力である Git にあるので、複写をやめ、作業ログは Git から導けない完了記録だけにする。
  軸: 表現不可能 — 時間は予定データの 1 か所、完了記録は作業ログの 1 か所に置く。
- D2: `plan`・`resched`・`slot open`・`slot overdue` を廃止する。
  先行例: ADR-1291 D4(「過ぎた」を状態にせず、終了時刻から毎回導く) docs/adr/1291-task-slot-worklog.md (取得 2026-10-30)
  差分: 一致 — 導く値を状態にしない方針は保つ。導く場所を、時間を持つ予定データ側(読む側)に移す。
  軸: 還元 — 担う仕事が予定データ側にある機構を、作業ログに残さない。
- D3: 鍵を予定データの予定 id にし、同じ鍵に別々の終端は書けず、先に書かれた終端が勝つ。
  先行例: ADR-1259 D4(鍵を設計し、冪等性と重複しない性質を鍵に持たせる) docs/adr/1259-mail-lifecycle.md (取得 2026-10-30)
  差分: 一致 — 外から与えられる鍵で、同じ事象の再実行は記録済みになる。ADR-1291 D3 の「鍵は使い回せない」は、鍵が自分で決める id だったことの帰結で、外の id では当てはまらない。
  軸: 表現不可能 — 書き込み口から、同じ鍵に別々の終端を書く経路を無くす。
- D4: 読み出しを `slot closed` にし、試験を語彙の遷移表の全マスで行う。
  先行例: ADR-1291 D5(語彙 JSON から読んだ遷移表の全マスを試験する) docs/adr/1291-task-slot-worklog.md (取得 2026-10-30)
  差分: 一致 — 表が小さくなる(none・2 状態 × 出来事 2)だけで、方法は同じ。
  軸: 検出のみ — 試験は表と実装のずれを検出するが、ずれを書けなくはしない。

## 却下した案

- `plan`・`resched` を残して、時間を作業ログにも持つ。D1 のとおり、時間が 2 か所で食い違い、作業ログはクラウドから読めない。
- `slot open`・`slot overdue` を残す。D2 のとおり、時間を持たない作業ログからは導けない。
- 終端の控え(機体ごとの JSON Lines)を足す。ADR-1291 の D6 のとおり、無人で書く `sweep` が無い。終端の行が消えれば、
  その枠は読む側から未記録に見え、本人が裁き直せる。

## Consequences

- 作業の枠の完了記録は、vault の当日ノートの `[slot]` 行から引ける。`worklog slot closed --json` が記録済みの鍵を
  返し、読む側が予定データの予定 id と突き合わせる。
- 時間枠を持つ旧い形の行(`plan:`・`resched:`)は、解析できない行として `slot check` に出る(exit 1)。この kind は
  ADR-1291 と同じ日に足したので、本番のノートに残っている見込みは小さい。残っていれば手で消す。
- 限界: 終端の行の手削除は検出しない。切り替え日(`2026-10-30`)より前のノートは畳み込まない。読む範囲は `list` の
  上限(400 日)に収まる分までで、それより前に記録した鍵は引けなくなる。
