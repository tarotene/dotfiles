メール裁定

の一括処理。押した裁定は、この画面と記録の保存先に残り、次の机か次のセッションが読んで、記録(worklog)に書きます。

保存先に接続中です。

判断の表

種類ごとの枠に並べています。返信の下書きは、その項目の枠の中にあります。「対応する」「見送る」は記録に decide・pass として書かれます。「あとで」は何も書かず、7 日で再通知が出ます。各項目のメモ欄には、その裁定の理由や、次から変えてほしいことを書けます。「未確認」は、本文を読んでいない、または使っているサービスか分からないものです。

今後の裁定へのフィードバック

この裁定と、これ以降の推奨の出し方への注文を、自由に書いてください(例: セキュリティ通知は期限が無くても先に出す)。次の机が読んで、推奨に反映します。メモには結論と理由だけを書き、パスワードやアドレスは書かないでください。
